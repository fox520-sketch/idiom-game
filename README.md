# 成語大挑戰進階版 v3.1

這是可直接部署到 GitHub Pages 的成語填空網頁遊戲。

## v3.1 新增功能

- 答題動畫：答對、答錯會有視覺提示
- 音效與靜音：答對、答錯、倒數、結束音效，可一鍵關閉
- 連續答對加分：連續答對 3、5、10 題會有額外分數
- 注音開關：一般、快速、每日挑戰可選擇是否顯示注音；考試模式預設隱藏注音
- 題庫分類統計：顯示總題數、分類數、難度數與各分類題數
- 題庫品質檢查：檢查缺注音、缺例句、缺解釋、重複題目、答案不在完整成語內等問題

## 保留功能

- 八選一作答
- 一般遊戲
- 快速遊戲
- 錯題本與錯題複習
- 學習紀錄
- 成語學習卡
- 每日挑戰
- 考試模式
- 成就徽章
- 題庫搜尋
- 題目回報
- 分享成績
- 自然模式、深色模式、黑白模式

## GitHub Pages 上傳方式

請將以下檔案放在 repository 第一層：

```text
index.html
idioms.js
README.md
```

`.gitignore` 可上傳，也可以不傳，不影響網站運作。
