# 成語大挑戰 v4.2 手機版 UI 全面優化版

這是可上傳到 GitHub Pages 的成語填空八選一學習遊戲，包含單人練習、快速遊戲、每日挑戰、考試模式、題庫學習、PWA 離線功能，以及 Firebase 多人搶答。

## v4.2 新增重點

- 手機版首頁與選單重新排版，按鈕更適合觸控。
- 手機版一般遊戲與多人搶答答案固定一行 2 個。
- 多人搶答手機版題目、注音、答案、排名與房主工具重新調整。
- 導覽列、統計卡、表格與列印/學習工具在小螢幕更不容易擠壓。
- 更新 PWA 快取版本，降低上傳新版後仍看到舊畫面的機率。


- 題庫擴充到 1000 題
- 每題包含：成語、缺字題、答案、注音、解釋、例句、提示、難度、分類
- 保留 v4.0 多人遊戲正式版功能

1. 多人等待室加入「準備 / 取消準備」狀態。
2. 玩家清單會顯示房主、已準備、未準備。
3. 房主開始遊戲前會提醒尚未準備的玩家。
4. 多人遊戲中房主可手動「下一題」。
5. 多人遊戲中房主可手動「結束本局」。
6. 完整成績表可一鍵複製，方便貼到 LINE 或紀錄。
7. 保留 Firebase 匿名登入安全版規則。
8. 保留 QR Code 邀請、同房再玩一局、房主設定題數/秒數/分類/難度。

## 上傳 GitHub

請把以下檔案放在 repository 第一層：

- index.html
- idioms.js
- README.md
- manifest.json
- service-worker.js
- firestore.rules

請保留你原本已經填好的 `firebase-config.js`，不要覆蓋。

## Firebase

請確認已開啟：

- Authentication → Anonymous
- Firestore Database
- Firestore Rules 已更新為本版 `firestore.rules`
