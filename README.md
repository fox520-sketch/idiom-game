# 成語大挑戰正式版 v3.0

這是可直接部署到 GitHub Pages 的成語填空網頁遊戲。

## v3.0 新增功能

- 每日挑戰：每天固定 10 題挑戰。
- 考試模式：不提供提示，作答後不立即公布答案，結束後再看錯題。
- 成就徽章：依照作答數、連勝、滿分、每日挑戰等條件解鎖。
- 題庫搜尋：在成語學習卡中可搜尋成語、注音、解釋、分類。
- 題目回報：可針對目前題目產生回報文字，方便修正題庫。

## 上傳方式

請把以下檔案放在 GitHub repository 第一層：

```text
index.html
idioms.js
README.md
```

GitHub Pages 設定：

```text
Settings → Pages → Deploy from a branch → main / root
```
