# 成語大挑戰 v3.4 教材與題庫管理版

這是可部署到 GitHub Pages 的成語填空八選一學習遊戲。

## v3.4 新增功能

1. 老師出題模式
2. 自訂題庫匯入
3. 題庫管理工具
4. 錯題列印學習單
5. 考試成績單
6. PWA 更新提醒

## 保留功能

- 八選一作答
- 一般遊戲 / 快速遊戲 / 每日挑戰 / 考試模式
- 錯題本、智慧複習、弱點分析
- 收藏成語、我的成語筆記
- 匯出 / 匯入學習紀錄
- 練習卷 / 答案卷與列印
- 離線可用 PWA
- 本機排行榜
- 題庫品質檢查

## 上傳 GitHub Pages

請把以下檔案放在 repository 第一層：

```text
index.html
idioms.js
README.md
manifest.json
service-worker.js
```

`.gitignore` 可以不用上傳。

## PWA 更新提醒

本版加入更新提醒。如果上傳新版後看到舊畫面，請按網頁中的「立即更新」，或清除瀏覽器快取後重新開啟。
