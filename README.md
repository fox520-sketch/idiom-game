# 成語填空小遊戲

這是一個可以直接上傳到 GitHub Pages 的單機版成語填空網頁遊戲。

## 功能

- 成語填空題
- 可輸入答案，也可點選選項
- 計分功能
- 提示功能
- 成語解釋
- 手機版適配
- 自然模式、深色模式、黑白電子紙模式
- 上方連結回狐狸之家

## 上傳 GitHub Pages 方法

1. 建立新的 GitHub repository，例如 `idiom-game`
2. 上傳本專案所有檔案
3. 到 `Settings` → `Pages`
4. Source 選擇 `Deploy from a branch`
5. Branch 選擇 `main`，資料夾選擇 `/root`
6. 儲存後等待部署完成

完成後網址通常會是：

```text
https://fox520-sketch.github.io/idiom-game/
```
