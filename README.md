# 成語大挑戰 v4.6.2 題庫 2000 題注音修正版

這是可上傳到 GitHub Pages 的成語填空八選一學習遊戲，包含單人練習、快速遊戲、每日挑戰、考試模式、題庫學習、老師班級版、PWA 離線功能，以及 Firebase 多人搶答。

## v4.6.2 新增重點

1. Firebase 安全規則強化：匿名登入後才能讀寫，多人房間、玩家、答案與診斷資料權限更清楚。
2. 過期房間與舊資料清理：新增資料清理頁，可清除本機舊快取並由房主關閉目前房間。
3. 錯誤診斷頁面：可檢查 Firebase 設定、匿名登入、Firestore 寫入、PWA 快取與瀏覽器資訊。
4. 題庫健康檢查強化：增加缺字題長度、注音可疑字元、注音音節數、重複缺字題等檢查。
5. 手機多人流程優化：掃 QR Code 或邀請連結後自動帶入房號並提示輸入暱稱加入等待室。
6. 新增操作教學頁：整理單人、多人、老師班級版、更新與離線使用方式。

## 上傳 GitHub

請把以下檔案放在 repository 第一層：

- index.html
- idioms.js
- README.md
- manifest.json
- service-worker.js
- firestore.rules

請保留你原本已經填好的 `firebase-config.js`，不要覆蓋。

## Firebase

請確認已開啟：

- Authentication → Sign-in method → Anonymous → Enable
- Firestore Database
- Firestore Database → Rules 已更新為本版 `firestore.rules`

## 更新後看不到新版時

因為本專案支援 PWA 離線快取，上傳新版後若畫面仍是舊版，請：

1. 按網頁上方「立即更新」；或
2. 進入「錯誤診斷頁面」按「清除快取並重新載入」；或
3. 手機瀏覽器清除這個網站的快取後重新開啟。
