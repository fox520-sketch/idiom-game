# 成語大挑戰 v3.3 教學與離線強化版

這是可直接上傳 GitHub Pages 的成語填空網頁遊戲。

## v3.3 新增功能

1. 練習卷 / 答案卷：可依難度、分類、題數產生，可列印。
2. 列印功能：練習卷、答案卷、錯題與收藏內容可用瀏覽器列印。
3. 離線可用 PWA：加入 `manifest.json` 與 `service-worker.js`，開啟過一次後可離線使用。
4. 資料備份提醒：作答一段時間後提醒匯出學習資料。
5. 錯題熟練度系統：待複習、加強練習、逐漸熟悉、已掌握。
6. 本機排行榜：保存分數、正確率、時間與模式紀錄。

## 上傳 GitHub Pages

請把以下檔案放在 repository 第一層：

- `index.html`
- `idioms.js`
- `README.md`
- `manifest.json`
- `service-worker.js`

`.gitignore` 可上傳，也可以省略。

## 注意

PWA 離線快取可能會讓舊版頁面暫時保留。更新新版後，若畫面沒有變，請按 Ctrl + F5，或清除網站快取後重新開啟。
