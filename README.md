# 成語填空小遊戲 v2.3 學習強化版

這是一個可以直接上傳到 GitHub Pages 的成語填空網頁遊戲。

## v2.3 新功能

- 固定四選一作答
- 增加倒數計時，可選不限時間、20 秒、15 秒、10 秒
- 增加錯題本，答錯會自動保存到瀏覽器
- 增加錯題複習模式
- 增加成語例句顯示
- 增加首頁選單
- 保留難度、分類、題數、自然模式、深色模式、黑白模式
- 保留「回狐狸之家」連結

## 上傳 GitHub Pages

請把以下檔案放在 repository 第一層：

```text
index.html
idioms.js
README.md
```

`.gitignore` 可以不用上傳，不影響網站運作。

## 題庫格式

題庫在 `idioms.js` 裡，每題格式如下：

```javascript
{
  full: "掩耳盜鈴",
  blank: "掩耳盜＿",
  answer: "鈴",
  hint: "會發出聲音的小物",
  meaning: "比喻自欺欺人。",
  level: "簡單",
  category: "故事寓言",
  example: "他明明知道自己錯了，卻假裝沒事，真是掩耳盜鈴。"
}
```

`example` 可以不填，遊戲會自動產生簡易例句；但建議以後新增題庫時補上自己的例句，學習效果會更好。
