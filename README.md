# 成語大挑戰 v3.2 題庫與複習強化版

這是一個可直接部署到 GitHub Pages 的成語填空網頁遊戲。

## v3.2 新增功能

1. 題庫擴充到 500 題
2. 增加弱點分類分析
3. 增加智慧複習模式
4. 增加收藏成語
5. 增加我的成語筆記
6. 增加匯出 / 匯入學習紀錄

- 一般遊戲

## 上傳 GitHub Pages

請把以下檔案放在 repository 第一層：

```text
index.html
idioms.js
README.md
```

不要只上傳整個資料夾，否則 GitHub Pages 可能會找不到首頁。

## 題庫格式

每一題建議維持以下格式：

```javascript
{
  full: "畫蛇添足",
  blank: "畫＿添足",
  answer: "蛇",
  hint: "一種爬行動物",
  meaning: "比喻多此一舉，反而壞事。",
  level: "簡單",
  category: "動物成語",
  zhuyin: "ㄏㄨㄚˋ ㄕㄜˊ ㄊㄧㄢ ㄗㄨˊ",
  example: "做報告不要加入無關圖片，否則會畫蛇添足。"
}
```
