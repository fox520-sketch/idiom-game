# 成語填空小遊戲 v2.5 題庫擴充與學習紀錄強化版

這是一個可以直接上傳 GitHub Pages 的成語填空網頁遊戲。

## v2.5 新增功能

1. 題庫擴充：由原本 103 題擴充到 238 題以上。
2. 學習紀錄：總作答、答對、答錯、正確率、遊玩次數、最高分、最高連續答對、最近遊玩日期。
3. 錯題本加強：可以只練錯題、清除錯題；錯題複習答對 2 次後會自動移出錯題本。
4. 成語學習卡：可先看完整成語、注音、意思、例句、分類與難度。
5. 注音欄位：`idioms.js` 每題都有 `zhuyin` 欄位，可自行補充或修改。
6. 分享成績按鈕：遊戲結束後可複製成績文字分享給朋友。

## 上傳 GitHub Pages

請把這些檔案放在 repository 第一層：

```text
index.html
idioms.js
README.md
```

`.gitignore` 可上傳，也可以不傳，不影響網站運作。

## 修改題庫

打開 `idioms.js`，依照格式新增題目：

```javascript
{ full: "掩耳盜鈴", blank: "掩耳盜＿", answer: "鈴", hint: "會發出聲音的小物", meaning: "比喻自欺欺人。", level: "簡單", category: "故事寓言", zhuyin: "ㄧㄢˇ ㄦˇ ㄉㄠˋ ㄌㄧㄥˊ", example: "他明明知道錯了還假裝沒事，真是掩耳盜鈴。" }
```
